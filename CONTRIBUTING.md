# Contributing

Start with the [development guide](docs/development.md) to build the project and locate the code and tests for your
change.

Keep each pull request focused. Include a regression test for behavior changes and update the
[mapping reference](docs/output.md) when the JSON form changes. Record user-facing changes under
[Unreleased](CHANGELOG.md#unreleased).

Use [Conventional Commits](https://www.conventionalcommits.org) and run the
[pull request checks](docs/development.md#pull-requests) before submitting.

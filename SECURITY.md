# Reporting a security issue

Use **Report a vulnerability** in the repository's [Security tab](https://github.com/sminodev/xsd-to-jsonschema/security)
to contact the maintainer privately. If the button is unavailable, open an issue asking for a private reporting channel.
Keep the technical details and any affected files out of that issue.

In the private report, include the package and Node.js versions, the affected entry point, the impact you observed
and the smallest example that demonstrates the problem. Use synthetic data in example schemas and documents.
